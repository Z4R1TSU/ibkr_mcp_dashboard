# GOOG 研究价格混用排查与修复

2026-10-29 任务 `9dfddef7` 的行情审计使用 thinkorswim 日线，最新已完成交易日为 10 月 28 日，收盘为 321.89 USD。任务附带的持仓价格为 290.53，嘉信独立 last / mark 为 291.54 / 291.60。综合结论提到了差异，技术章节仍以历史收盘推导当前支撑、阻力和评级。

原因是研究只主动查询历史日线；最新报价随账户缓存附带传入，没有统一注入各阶段，也没有程序校验报告中的价格依据。证据不足以认定 321.89 这个历史收盘本身错误。

## 修复

- Node 后台任务主动读取嘉信报价，失败时复用现有 IB 客户端及只读队列；未持有股票也支持查询，精确匹配 IB 美股合约。
- 嘉信新增本机鉴权 GET /v1/quote，限定标的、队列和请求时限。真实联调确认 quotes/get 使用 BID / ASK / LAST / LAST_RTH / VOLUME；加入 MARK 的请求返回失败，已改回支持的字段。
- 最新参考价、历史日线、持仓估值分别保存；统一价格上下文注入所有研究角色。来源未给成交时间时保留未知，不把接收时间解释为成交时间。
- 最新价与历史技术位的关系及百分比由程序计算，通过结构化引用渲染；价格校验失败时阻止发布方向性结论。日线截止日使用美股交易日历及结算缓冲。
- 任务目录保留 market-context.json、price-facts.json、price-validation.json；既有历史报告不覆盖。
